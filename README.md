# Movie REST API

A RESTful API for managing movies, built with **C#** and **ASP.NET Core** as a hands-on backend development project.

The project was initially developed while following a REST API course by **Nick Chapsas** and was further customized and extended as part of my backend development practice.

## Features

* Create, retrieve, update, and delete movies
* RESTful API endpoints
* JWT-based Authentication
* Role-based Authorization
* API Versioning
* Health Checks
* Request and response contracts
* Separation of API, application, and contract concerns

## Technologies

* **C#**
* **ASP.NET Core**
* **Entity Framework Core**
* **SQL Server**
* **JWT Authentication & Authorization**
* **API Versioning**
* **Health Checks**
* **Git / GitHub**

## Project Structure

```text

│

│
```

## Purpose

The main purpose of this project was to practice building RESTful backend services with ASP.NET Core and to gain practical experience with API design, authentication, authorization, and application structure.

This project later served as the foundation for **MovieApp**, a more advanced version developed using **Clean Architecture** and additional backend development practices.
